Pareto-DPO

Scalarization-free multi-objective preference alignment for generative genomic sequence design.

What it does

Pareto-DPO aligns a generative nucleotide-sequence model to multiple competing objectives (for example, on-target efficacy and off-target suppression in CRISPR sgRNA design) without scalarization. The optimiser is standard Direct Preference Optimization; the contribution is how the preferences are built:

  • Score candidate sequences on each objective with external oracles.
  • Keep a preference pair only when one candidate Pareto-dominates the other; exclude mutually incomparable candidates.
  • Train with standard DPO on that preference set — no objective weighting anywhere.

The whole pipeline is engineered to run on a single 8 GB consumer GPU (< 0.6 GB peak VRAM).
