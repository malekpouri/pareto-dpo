What it does

Pareto-DPO aligns a generative nucleotide-sequence model to multiple competing objectives (for example on-target efficacy and off-target suppression in CRISPR sgRNA design) without scalarization. The optimiser is standard Direct Preference Optimization; the contribution is how the preferences are built.

1 · Score each candidate on every objective (external oracles)
→
2 · Pareto dominance keep a pair only if one dominates; drop incomparable ones
→
3 · Standard DPO train on that preference set — no weighting
  • No relative weight over objectives is chosen at any stage.
  • Excluding incomparable pairs leaves generative density free across the frontier — which helps preserve diversity.
  • Engineered for a single 8 GB consumer GPU: < 0.6 GB peak VRAM via offline reference-log-prob caching, a compact ~1.8 M-parameter policy, and BF16 gradient accumulation.

Get started

git clone https://github.com/malekpouri/pareto-dpo && cd pareto-dpo
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt      # install a CUDA torch build for your GPU
bash reproduce.sh                    # run the full seeded pipeline

Running the pipeline needs input datasets that are not bundled here (CRISPRon scores, whole-genome near-match tables, a GRCh38 reference); see the docstrings in scripts/01_build_preference_pairs.py and scripts/_eval_oracles.py.
